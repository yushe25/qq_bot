# 0002. 自主学习只学表达不学身份

- 状态：accepted
- 日期：2026-09-09
- 关联文档：docs/design-contracts/learning-style.md、AGENTS.md

## 背景

希望机器人从群友说话风格中学习，加强仿真。风险是模型学到个人隐私、违规表达或特定真人的身份特征，导致人设失控和隐私问题。

## 决策

- 学习范围限定为 `speech_style`、`group_norm`、`topic_trend`。
- 学习结果只作为低优先级表达建议，永远不能覆盖 persona 身份、禁忌和系统安全规则。
- 支持按成员排除学习、笔记上限、置信度过滤、敏感内容拒绝和过期。
- 禁止复制具体真人；私密信息与违规模板一律不采集。

## 后果

优点：机器人会逐渐更像“这个群的一员”，同时保持独立人设和可控边界。
缺点：需要持续维护过滤规则和删除入口；学习质量依赖人工抽查，不能完全自动化放任。
