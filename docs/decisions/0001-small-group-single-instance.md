# 0001. 项目定位为小群单机运行时

- 状态：accepted
- 日期：2026-09-09
- 关联文档：README.md、AGENTS.md、docs/design-contracts/schedule-behavior.md

## 背景

项目是私人使用，只在最多 20 人的小群运行；开源后也不面向大群。上一轮方案曾包含多账号、Docker、企业级控制台等面向规模的建议，与项目目标不符。

## 决策

- QQF 定位为单机、单实例、小群仿真运行时。
- 新增 `safety.maxGroupMembers`，默认 20；成员数超过上限时只读不发言并写审计。
- 不接受多账号、多实例集群、复杂权限体系、RAG 和大群运营能力。
- 开源仓库不含真实密钥、真实群号和聊天样本。

## 后果

优点：开发资源集中在拟真度和稳定性，部署和运维成本极低。
缺点：大群或强运营场景需要另起分支，不能直接复用当前方案作为通用平台。
