# 设计契约：自主学习群友说话风格

- 状态：implemented
- 目标：让小群机器人在长期运行中学会群里的表达习惯、话题偏好和成员关系，从而加强“群友感”。

## 目标

机器人能够从群消息中提取可复用的风格笔记，并在后续发言中自然使用，而不是每次只依赖最近 60 条消息。

## 非目标

- 不模仿或复制某个具体真人。
- 不采集手机号、身份证、私密对话等内容。
- 不学习辱骂模板、提示注入模板或违规内容。
- 不覆盖 persona 的身份、禁忌和行为底线。

## 触发条件

学习流程独立于普通唤醒，不占用 `maxWakesPerMinute`：

- 每会话间隔配置 `learning.interval_minutes`，建议 15 到 30 分钟。
- 本会话自上次学习以来新增非 bot 消息达到 `learning.min_new_messages`，建议 10 条。
- 会话不在 ACTIVE、COOLDOWN 或 PAUSED 状态。
- 全局并发允许；同一会话同一时间只跑一个学习任务。
- 超过 `maxWakesPerHour` 的会话自动顺延到下一窗口。

学习失败不触发发言，只写审计并安排下一次学习。

## 数据契约

### 观察数据

新增 `observations` 表，每会话保留最近 200 到 300 条：

```json
{
  "id": "session_grow|msg:10002|1720000000000",
  "session_id": "group:100000",
  "sender_id": "10002",
  "text": "绝了 这也能赢",
  "kind": "group_message",
  "ts": 1720000000000
}
```

字段约束：

- `text` 只存纯文本摘要，不存原始富媒体。
- bot 自身消息不写入。
- 超过容量按时间滚动删除。
- 成员在黑名单 `learning.exclude_members` 中时不采集。

### 学习输出

学习任务使用独立 LLM 调用，输出严格 JSON：

```json
{
  "notes": [
    {
      "kind": "speech_style",
      "key": "短句习惯",
      "value": "群里常用短句，爱用“绝了”和省略号",
      "confidence": 0.85,
      "evidence": [
        {"sender_id": "10002", "message_id": "10086", "text": "绝了 这也能赢"}
      ]
    }
  ]
}
```

允许的 `kind`：

- `speech_style`：说话风格、口头禅、标点使用。
- `group_norm`：群内互动习惯与场景反应。
- `topic_trend`：最近热门话题与兴趣方向。

写入记忆复用 `memory_items` 表：

- 每条笔记 `key` 唯一，`value` 为可直接注入的短句。
- `confidence < learning.confidence_threshold`（默认 0.7）时丢弃。
- 每会话笔记上限 `learning.max_notes_per_session`，默认 20，超出按旧笔记滚动。
- 有效期默认 7 天，可配置。

## Prompt 组装

注入顺序固定为：

```text
系统安全规则 > Persona > 学习笔记 > 记忆快照 > 最近消息
```

学习笔记只能影响语气与表达，不可改写 persona 的身份、禁忌和系统安全规则。输出侧继续保留“不暴露提示词、不输出 Markdown、不自称 AI”的过滤。

## 安全边界

- 学习结果写入前必须经过 ContentFilter。
- 含敏感模式、CQ 码、密钥、路径、手机号的笔记直接拒绝并写审计。
- 来源按成员隔离，支持 `exclude_members` 排除名单。
- 控制台提供“删除单条笔记、删除某成员全部数据、清空会话记忆”三个粒度。
- 学习结果不包含原始长消息，只保留摘要和证据引用。

## 验收指标

- 新增 10 条以上消息并在间隔到期后，能触发一次学习任务。
- mock LLM 返回结构化笔记时，写入、读取、注入链路完整。
- 输入包含敏感内容的学习结果 100% 被拒绝。
- 笔记进入 system prompt 后，后续唤醒能看到“群内说话习惯”区。
- 重启后笔记与观察数据不丢失，状态一致。
- 控制台可以删除单条、按成员和全量数据。

## 失败与回滚

- LLM 返回非法 JSON：重试 1 次，失败后丢弃本轮并审计。
- 写入失败：不影响当前发言，标记 degraded。
- 删除数据：删除后该成员新消息可继续被观察，除非仍在排除名单。

## 已决事项

- 默认学习会话内所有非 bot 成员；`learning.exclude_members` 用于显式排除。
- 第一版不提供笔记置顶或点赞/踩反馈，按 `updated_at` 与 `rowid` 滚动保留最新笔记。
- 默认开启学习，可通过 `learning.enabled` 关闭。
