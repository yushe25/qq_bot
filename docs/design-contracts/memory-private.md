# 设计契约：轻量记忆与 owner 私聊

- 状态：implemented
- 目标：让机器人跨唤醒保留少量稳定的群内上下文，并让 owner 私聊走与群聊相同的安全门禁。

## 目标

- 记忆只保存能改善后续群聊连续性、体积可控的短信息。
- 旧记忆随时间衰减，避免历史话题长期压过当前上下文。
- 快照限制条数与单条长度，防止记忆无限膨胀成 token 大坑。
- 提供最小化的 `qq_send_private_message`，支持 owner 私聊和当前私聊会话回复。
- 所有私聊发送继续经过白名单、内容过滤、频率限制、每日上限、审计和单次唤醒上限。

## 非目标

- 不建立知识库、向量检索或长期事实数据库。
- 不为模型提供任意 QQ 号私聊能力。
- 不新增私聊群发、好友管理、文件发送或跨会话记忆。
- 不让记忆覆盖 persona 的身份、禁忌和安全规则。

## 记忆契约

### 允许的 kind

- `active_topic`：当前仍在延续的话题，基础重要性 3，有效期 7 天。
- `pending_thought`：尚未接完的话或待跟进事项，基础重要性 2，有效期 14 天。
- `impression`：对群成员或互动方式的轻量印象，基础重要性 1，有效期 30 天。

其他 kind 一律拒绝。学习笔记 `speech_style`、`group_norm`、`topic_trend` 只出现在“群内说话习惯”区块，不进入记忆快照。

### 写入

模型通过 `memory_update` 写入：

```json
{
  "kind": "active_topic",
  "key": "当前话题",
  "value": "群里刚聊到周末开黑"
}
```

- `key` 和 `value` 必须是非空字符串。
- `key` 最长 80 字符，`value` 最长 300 字符。
- 同一会话内 `(kind, key)` 为唯一键；重复写入时覆盖 value 并刷新 `updated_at` 与过期时间。
- 写入失败返回工具错误，不中断当前唤醒的其他工具。

### 衰减与排序

`updated_at` 是排序基准。记忆分数定义如下：

```text
score = base_importance - 0.75 * age_days
```

排序优先级为：`score DESC`、`updated_at DESC`、`kind`、`key`。已经过期的记忆不参与排序或注入。

### 快照

- 一次最多选择 12 条记录。
- 每条 value 去掉换行、首尾空白并按 120 字符截断。
- 按 kind 分组为“当前话题”“未完成念头”“成员印象”三行。
- 分组顺序按组内最高分决定，使刚出现的重要上下文能排在前面。
- 没有记录时输出 `（暂无记忆）`。

## 私聊契约

### 工具

```json
{
  "name": "qq_send_private_message",
  "arguments": {
    "userId": "100001",
    "message": "收到"
  }
}
```

- 当前会话是私聊时，`userId` 必须等于当前 `scene_id`。
- 当前会话是群聊时，`userId` 必须等于 `qq.ownerQq`。
- owner 未配置或目标不是 owner 时拒绝。
- 单次唤醒排队数量继续受 `safety.maxSendsPerWake` 限制。

### 安全边界

- 工具只排队，不直接发送。
- `SafetyPipeline` 发送前再次检查私聊白名单、内容过滤、每分钟/每小时限流和每日上限。
- 每次放行、拒绝和发送失败都写审计。
- 不允许模型通过参数覆盖当前会话、owner 配置或安全配置。

## 验收指标

- 非法记忆 kind 被拒绝，合法写入可在快照中读取。
- 过期或学习类记录不进入记忆快照。
- 旧的高重要性记录会因时间衰减排到新的普通记录之后。
- 快照总条数不超过 12，单条 value 不超过 120 字符。
- mock `@` 唤醒真实调用 `memory_update`，后续唤醒的 invocation 能看到刚写入的记忆。
- owner 私聊和当前私聊会话可以发送；其他目标、非白名单、敏感内容、限流或每日上限命中时拒绝。
- 成功和失败的私聊动作均可从审计日志追溯。

## 失败与回滚

- 记忆写入异常只让该工具返回失败，其他工具继续执行。
- 私聊发送前校验失败时不消费频率额度。
- 重启后记忆读写、过期和私聊配置仍以 SQLite 与配置文件为准。
- 回滚时可移除私聊工具 schema 与 dispatch；已有记忆记录可按 kind 清理，不影响会话和审计数据。

## 开放问题

- 暂无。契约外的自动记忆提炼、记忆合并和私聊历史属于后续独立功能。
